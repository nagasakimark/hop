🎙️ Megane Hop — Voice Studio

Record each word below, one file per word. Words save as voices/sun.mp3, sounds as sounds/s.mp3. The list comes straight from the game's course, so it always matches what the game says. Anything not recorded is spoken by the computer voice instead.

checking…

How to record: 1) Enable microphone  2) press ● on a card, say the word clearly, press ■  3) press ▶ to check it, re-record if needed. Silence at the start/end is trimmed automatically. Tip: record in a quiet room, keep the same distance from the mic, and say each word the way you want kids to hear it in the game.
Already recorded? Cards turn blue when the file is already in the game's voices/, sounds/ or phrases/ folder, so you only need to record what's left. (This check works when this page is opened from the game folder.)
The game plays .mp3 files. If the MP3 encoder can't load (offline), recordings are saved as .wav, which the game can't use — record those again when you're online.

Words

Every word the game can speak (questions, lessons, practice, review).

Letter & pattern sounds

Lessons say these before the example words ("sss… sun, sock"), and the early levels ask "hear the sound, pick the letter". Say just the sound, not the letter name. Without a recording the game skips the sound and uses the example word.

Praise

Optional. Short cheers in your voice. The computer voice never says these.
